# Documentation

This directory contains organized documentation for issues and implementations.

## Structure

- `issues/` - Track bugs, problems, and issues encountered during development
- `implementations/` - Document solutions, fixes, and feature implementations

## Usage

When you encounter a bug or issue:
1. Create a markdown file in `issues/` describing the problem
2. Include steps to reproduce, error messages, and relevant context

When implementing a fix or feature:
1. Create a markdown file in `implementations/` documenting the solution
2. Include approach, code changes, and any relevant notes
